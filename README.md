# Dynamic Island PC

Оверлей в стиле Dynamic Island с macOS, но для Windows. Висит сверху экрана, сворачивается в точку или показывает время, раскрывается по наведению мыши и превращается в мини-дашборд.

Не просто виджет — полноценный центр управления: микшер громкости по приложениям, буфер обмена с историей, полка файлов с drag-and-drop, медиа-плеер с размытым фоном обложки, мониторинг системы, VPN-переключатель и быстрые действия.

![preview](docs/preview.png)

## Зачем это вообще

Мне надоело переключаться между окнами, чтобы поменять громкость Discord, посмотреть что играет в Spotify, скопировать что-то из буфера или перетащить файл. Всё это делается в одном месте, не отрываясь от текущей задачи.

Плюс это просто красиво выглядит.

## Что умеет

### 🎵 Медиа-центр
- Показывает текущий трек из любого приложения, которое поддерживает Windows SMTC (Spotify, YouTube в браузере, VLC, Apple Music и т.д.)
- Размытая обложка на фоне панели — как в macOS Now Playing
- Кликабельный прогресс-бар: кликнул в любое место — перемотал
- Отдельный ползунок громкости именно для плеера (не системный)
- История последних 5 треков с временем
- Кнопка «Открыть приложение» — переключает фокус на плеер
- Shuffle/Repeat индикаторы

### 🎚️ Микшер громкости
- Список всех активных приложений с ползунками
- Группировка: Браузеры / Игры / Музыка / Системные / Другие
- Пресеты одной кнопкой: «Игры», «Работа», «Кино» — настраивают громкость и мьют сразу для всех
- Mute All / Unmute All
- Поиск по приложениям

### 📋 Буфер обмена
- Хранит историю: текст, картинки, цвета, ссылки
- Фильтры: только текст / картинки / цвета / ссылки
- Поиск по содержимому
- Клик по записи — вставляет её обратно
- Удаление отдельных записей

### 📁 Полка файлов
- Перетаскиваешь файлы на остров — они сохраняются
- Сетка превью для картинок (110×80)
- Сортировка: по дате / имени / размеру
- Фильтр «только картинки»
- Drag-and-drop обратно на рабочий стол или в проводник
- Правый клик — показать в папке

### 🎧 Аудио-панель
- Все устройства вывода списком
- Переключение в один клик
- Визуальное выделение активного устройства

### 📊 Системный монитор
- Топ-5 процессов по CPU и RAM в реальном времени
- Кнопка «Освободить RAM» (GC.Collect)
- Регулировка яркости (WMI для ноутбуков, гамма для десктопов)
- Ночной свет (тёплый гамма-фильтр)

### 🛡️ VPN
- Подключение/отключение через rasdial
- Индикатор в шапке острова

### ⚡ Быстрые действия
- 📌 Закрепить остров (чтобы не сворачивался)
- 📸 Скриншот всего экрана (Ctrl+Alt+S) — сразу летит на полку
- 🔁 Быстрое переключение аудиоустройства
- 🌙 Не беспокоить (отключает OSD)

## Как ведёт себя остров

- **На рабочем столе** — сворачивается в полоску со временем и кольцами CPU/RAM/GPU
- **Над любым окном** — сворачивается в точку (чтобы не мешать)
- **Наводишь мышь** — раскрывается в дашборд 640×520
- **Кликаешь на плитку** — она морфится на весь остров, остальные исчезают
- **Возврат**: клик по шапке / Esc / правая кнопка мыши по панели

## Установка

1. Клонируй репозиторий
2. Открой `DynamicIslandPC.sln` в Visual Studio 2022+
3. Убедись, что Target Framework — `net8.0-windows10.0.19041.0` (нужно для WinRT SMTC API)
4. Положи `SoundVolumeView.exe` (от NirSoft) в папку `tools/` рядом с проектом — без него не будет работать системный микшер
5. Build → Run

### Зависимости
- **NAudio** — для работы с аудиоустройствами и сессиями
- **System.Management** — для яркости через WMI
- **WinRT API** (`Windows.Media.Control`) — для медиа-сессий (встроено в Windows 10/11 SDK)

## Архитектура

Проект на WPF (.NET 8), без MVVM-фреймворков — всё на code-behind с partial-классами.
